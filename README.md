# FleetLink - Logistics Vehicle Booking System

FleetLink is a platform for managing and booking logistics vehicles for B2B clients. It features a Node.js backend (Express, MongoDB), ReactJS frontend, and Dockerized deployment. Key features:
- Add vehicles
- Search available vehicles by capacity, route, and time
- Book vehicles with accurate availability checks
- Unit tests for backend logic

## Tech Stack
- Backend: Node.js (Express)
- Frontend: ReactJS
- Database: MongoDB
- Testing: Jest
- Docker: docker-compose

## How to Run
1. Build and start with Docker Compose
2. Access frontend at http://localhost:3000
3. Backend API at http://localhost:5000/api
